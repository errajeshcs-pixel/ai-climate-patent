# AI Climate Forecasting using Medallion Architecture

## Overview

This project implements an AI-powered climate forecasting framework using the Medallion Architecture and Ensemble Machine Learning.

The system integrates historical climate data, processes it through Bronze, Silver and Gold layers, and generates climate predictions using multiple ML models.

---

## Features

- Climate Data Integration
- Medallion Architecture
- Bronze-Silver-Gold Processing
- Ensemble Machine Learning
- Time Series Forecasting
- Interactive Dashboard
